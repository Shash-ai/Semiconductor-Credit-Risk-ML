# Phase 15E — Deterministic Stress & Monte Carlo Forensic Validation

## Purpose

Phase 15E separates two questions that must not be conflated:

1. Can the deterministic stress framework be reproduced exactly from the stored project risk components and documented stress transformation?
2. Are the archived Monte Carlo outputs internally consistent, and is there enough original method metadata to reproduce the stochastic experiment from scratch?

The deterministic layer is treated as an exact-reproduction test. The Monte Carlo layer is treated as a forensic evidence review until the original sampling implementation is recovered.

## Deterministic stress contract under test

The reconstructed Phase 3E score uses six normalized risk channels:

- project size: 0.25
- geographic concentration: 0.15
- electronics-credit growth: 0.15
- electronics-credit volatility: 0.15
- NPA growth: 0.15
- NPA addition pressure: 0.15

Only the four macro/banking channels are stressed. For severity `s`:

`stressed_risk = baseline_risk + s * (1 - baseline_risk)`

The stored scenario severities under test are baseline `0.00`, mild `0.10`, moderate `0.25`, and severe `0.50`.

The validation script recomputes every stored scenario score and rank and fails the deterministic gate if they do not reproduce to numerical tolerance. It also checks score bounds, risk bounds, monotonicity, and a broader severity grid.

## Monte Carlo evidence policy

The repository contains archived Monte Carlo project scores, project summaries, shock summaries, and system summaries. These artifacts are useful evidence, but their presence does **not** prove that the original stochastic method is reproducible.

Phase 15E therefore validates:

- shock-summary bounds and quantile ordering;
- system-summary simulation count, systemic-weight validity, and tail ordering;
- project-summary quantile ordering, dispersion, and nested top-k probabilities;
- reconstruction of archived project summaries from raw simulation scores where the raw schema permits it;
- candidate source-code/notebook hits that may contain missing method metadata.

The Monte Carlo gate remains open until the original method is verified, including the random seed/seed policy, exact shock distributions and parameters, systemic/idiosyncratic mixing equation, dependence rule, project-specific shock generation, score transformation, and portfolio aggregation formula.

A text search hit is only a lead for review; it is not automatically accepted as the original method.

## Interpretation guardrails

The stress score is a constructed research vulnerability/stress index, not a probability of default or expected loss. Monte Carlo uncertainty around that index is not a PD distribution. No PD, LGD, EAD, ECL, credit rating, or automatic lending decision is generated by this phase.
